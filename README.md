# Enterprise Multi-Site Network Infrastructure

**Cisco Packet Tracer · IPv4/IPv6 · VLANs · OSPF · DHCP · NAT · DNS**

A multi-site academic network project connecting Calgary, Red Deer, and Edmonton.

## What I worked on
- Site 3 IPv4 and IPv6 addressing
- VLSM subnet planning
- Router, switch, and gateway documentation
- Multi-site routing and connectivity concepts
- VLANs, OSPF, DHCP, NAT, and DNS

## Troubleshooting approach
Start with host addressing and gateways, then check VLAN/interface state, routing, and finally higher-level services.
